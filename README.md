# Custa Usado

MVP de consulta de preço médio de celulares usados no Brasil. Os dados são servidos pelo Supabase e o site é publicado no Vercel.

## Como funciona

- O catálogo contém iPhones (XR a 18) e Galaxies S (S20 a S26).
- As ofertas coletadas alimentam avaliações com mediana, faixa e confiança.
- A busca filtra os modelos já precificados.
